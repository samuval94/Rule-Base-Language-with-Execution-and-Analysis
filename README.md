### How to Run

#### Requirements

- Python 3.11 or higher installed.
- All six `.py` files must be in the **same folder**.

#### Input Format

The program reads from **standard input**. Input has two sections separated by the line `State:`:

```
rule <id>:
if <condition> then <action>

State:
<variable> = <integer>
<fact>
```

- **Rules section**: one or more rules before `State:`.
- **State section**: variable assignments (`id = integer`) and/or active facts (`id`), one per line.
- If there is no `State:` line, the initial state is empty.

#### Running on Windows (PowerShell)

```powershell
Get-Content tests/test1.txt | py main.py
```

#### Running on Linux / macOS

```bash
python3 main.py < tests/test1.txt
```

---

### Output Format

- Each activated fact is printed on a separate line, in **lexicographic order**.
- If no facts are activated, the output is exactly `(no output)`.
- Static analysis messages are printed after the execution output, preceded by a blank line and `Analysis:`.

### Grammar

The implemented grammar is the LL(1) transformation of the original specification:

```
Program   → RuleList EOF
RuleList  → Rule RuleList | ε
Rule      → RULE ID : IF Cond THEN Action
Cond      → Atom CondRest
CondRest  → AND Atom CondRest | ε
Atom      → ID AtomRest
AtomRest  → RelOp VALUE | ε
RelOp     → > | < | =
Action    → ID
```

Left recursion in `Cond → Cond AND Cond` was eliminated by introducing `CondRest`.

---

### Notes

- Keywords `rule`, `if`, `then` are lowercase; `AND` is uppercase. All are case-sensitive.
- Identifiers consist of letters, digits, and underscores, and must start with a letter.
- Integer values are base-10 and non-negative.
- No additional language features (OR, NOT, parentheses) are implemented.
